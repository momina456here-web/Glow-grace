
# Glow & Grace | Beauty Store 

Glow & Grace is a modern and responsive beauty e-commerce website featuring makeup, skincare, and beauty tools.

##  Features

- Elegant and modern user interface
- Responsive design for all devices
- Beauty product images and product cards
- Makeup, Skincare, and Beauty Tools categories
- Product category filtering
- Interactive shopping cart
- Add and remove products
- Increase and decrease product quantities
- Automatic subtotal calculation
- Pakistani Rupees (PKR) pricing
- Newsletter subscription form

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images

##  Project Structure

```text
Glow-Grace/
│
├── index.html

├── script.js
└── README.md
```

##  How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the Glow & Grace Beauty Store.

##  Website Sections

- Home
- Shop
- Collections
- About
- Newsletter
- Shopping Bag

##  Currency

All product prices are displayed in Pakistani Rupees (PKR).

## Developer

Developed as a Front-End Web Development Project.

##  Note

This project demonstrates front-end e-commerce functionality. Real online payments and order processing require backend integration.
